A deterministic Node 22 program that writes the worst superpower ever invented to `/output/entry.txt`: the ability to summon a single grain of sand once a day, anywhere on Earth except where you are standing. A real power, applied to the most worthless object imaginable, that its own hero can never even see or use.

## Run it

```sh
node main.ts
```
